# Referenser för omtaget

`stilguide-granskning.html` är granskningssidan för stilguiden, version 2 (5 oktober 2026). Den är en fristående prototyp, inte produktkod, men linjediagrammet under 4 "Indikatorn" (exempel 1.1) är godkänt som facit för utseende och beteende: inga legender, etiketter vid linjeslut, streckat rutnät, stabil hovring mot verkligt linjeavstånd, fast tooltip, fästa via klick eller "+ Jämför med region". Öppna filen direkt i webbläsaren.

Saknas i prototypen och ska byggas i produkten (stilguiden 6.8): hovring i förväntat intervall, staplar, små multiplar och rangordning samt ett galleri med spaghettigrafen för alla regioner.
